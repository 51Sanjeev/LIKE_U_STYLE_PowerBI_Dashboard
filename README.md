# LIKEUSTYLE E-Commerce Sales Dashboard

My first Business Intelligence project created using Power BI to practice data visualization, dashboard creation, and basic sales analysis.

## Dashboard Preview

![LIKEUSTYLE E-Commerce Sales Dashboard](Dashboard.png)

## About the Project

This project focuses on analyzing LIKEUSTYLE e-commerce sales data through an interactive Power BI dashboard.

The dashboard provides a simple view of sales performance across different states, categories, customers, payment modes, months, and sub-categories.

This is a learning project created to understand the basics of Business Intelligence and Power BI.

## Dashboard

The dashboard includes the following key metrics:

- Total Amount
- Total Profit
- Total Quantity
- Total AOV (Average Order Value)

It also provides visualizations for:

- Amount by State
- Quantity by Category
- Profit by Month
- Amount by Customer
- Quantity by Payment Mode
- Profit by Sub-Category

### Filters

The dashboard includes interactive filters/slicers such as:

- Quarter
- State

These allow the user to explore the data based on different selections.
